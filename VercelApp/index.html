Công Cụ So Sánh & Kiểm Thử Dữ Liệu Excel

Tùy chọn cột khóa đối chiếu (STT, Mã số...), phát hiện chênh lệch dữ liệu & xuất báo cáo Excel 3 sheet chuyên nghiệp
1 File Gốc (Chuẩn)
Hỗ trợ định dạng .xlsx, .xlsm (không giới hạn dung lượng)
Dữ liệu sẽ dùng cột này (ví dụ STT, Mã số, Mã NV) làm mốc để đối chiếu.
2 File Cần So Sánh
Hỗ trợ định dạng .xlsx, .xlsm (không giới hạn dung lượng)
Cột tương ứng ở file so sánh (ví dụ STT bên B khớp với STT bên A).
Mẹo Chọn "Lấy hết" khi bạn muốn đối chiếu toàn bộ các chữ số thập phân mà không bỏ qua bất kỳ sai khác nhỏ nào.
